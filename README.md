# macOS Keyboard Shortcuts

A single-page HTML infographic of common macOS keyboard shortcuts. Static site — no build step.

## Open locally

Open `index.html` in a browser, or from this directory:

```bash
open index.html
```

Or serve with any static server, for example:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

This project is meant to be published with GitHub Pages from the repository root (`index.html` at site root). After the repo exists on GitHub under `noodlebreak`, enable Pages for the default branch (or use your usual `push-to-git` flow).

Suggested public URL once Pages is on and the repo is named `mac-shortcuts`:

`https://noodlebreak.github.io/mac-shortcuts/`
