A quick map of the keys that actually matter — system, windows, Finder, screenshots, text, and Terminal. ⌘ is Command. ⌥ is Option. ⌃ is Control.

Terminal.app

New tab⌘+T
Close tab / pane⌘+W
Close window⌘+⇧+W
Split pane horizontally⌘+D
Close split pane⌘+⇧+D
Next / previous tab⌘+⇧+] / [
Clear screen⌘+K
Interrupt process⌃+C
EOF / exit shell⌃+D
Suspend process⌃+Z
Search scrollback⌘+F
Bigger / smaller text⌘++ / −

⌘D splits a pane — it does not close a tab. Use ⌘W to close, ⌃D to exit the shell.
